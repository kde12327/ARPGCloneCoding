## 🎮 프로젝트 개요

**패스 오브 엑자일(POE)** 스타일의 2D 액션 RPG를 목표로,  
게임의 구조적 설계와 핵심 시스템 구현을 중심으로 개발한 프로젝트입니다.

- 전투 시스템 (기본 공격 / 스킬)
- 아이템 시스템 (접두어/접미어, 플라스크, 젬 링크)
- 인벤토리/창고/상점 시스템
- 스탯 및 성장 구조
- 패시브 스킬 트리
- 퀘스트 연계 시스템
- 타일맵 기반 맵 이동 및 포탈
- UI 구성 (체력/마나/스킬/플라스크)

---

## ⚙️ 주요 기능 및 구현 방식

### 🗡️ 아이템 시스템
- CSV 기반 베이스 아이템 데이터 관리
- 접두어/접미어 옵션 + 랜덤 값 설정
- 장비 소켓 → 스킬 젬 장착 시스템
- 슬롯 타입/위치 기반 인벤토리 구조
- 크래프팅 아이템 사용 시 옵션 변경
- 플라스크 사용 처리

### 📈 스탯 및 성장 시스템
- 스탯 간 비례 효과 연동
- 브루트포스 방식의 패시브 트리 연결성 체크

### ⚔️ 전투 시스템
- 몬스터 추적 및 전투 AI
- 기본 공격 및 스킬 발동

### 📜 퀘스트 시스템
- 연계형 퀘스트 구성  
- 조건 만족 시 다음 퀘스트 자동 등록 (CSV 관리)

### 💎 스킬 시스템
- 메인 젬 + 보조 젬 연결  
- 보조 젬 효과에 따라 스킬 효과 변화

### 🧪 UI 시스템
- 체력 / 마나 / 스킬 단축키 / 플라스크 UI

### 🗺️ 맵 시스템
- Isometric 타일맵 기반 이동
- 각 맵은 독립된 씬으로 구성 (인스턴스 던전)
- 웨이포인트 & 포탈 이동 구현
